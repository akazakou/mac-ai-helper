Welcome to Mac AI Helper

A native macOS menu bar utility that captures selected text or screenshots via global keyboard shortcuts, sends content to AI providers, and displays responses with copy functionality.

Features

  • Global keyboard shortcuts from any application
  • Multiple AI providers: OpenAI, Anthropic (Claude), Google Gemini, OpenRouter
  • Custom prompt templates
  • Secure API key storage in macOS Keychain
  • Screenshot region capture with AI analysis

Requirements

  • macOS 14.0 (Sonoma) or later
  • Accessibility permission (to copy selected text)
  • Screen Recording permission (for screenshot feature)
