Getting Started

  1. Launch Mac AI Helper from your Applications folder
  2. Look for the icon in your menu bar (top-right of screen)
  3. Grant Accessibility permission when prompted
  4. Open Settings and add your AI provider API keys
  5. Start using: select text, press ⇧⌘C, pick a prompt!

Keyboard Shortcuts

  • ⇧⌘C — Capture text and show prompt popup
  • ⌃⌘C — Capture screenshot region

Enjoy using Mac AI Helper!
